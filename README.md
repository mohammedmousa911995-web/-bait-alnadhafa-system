# بيت النظافة - منظومة الحسابات

نسخة أولية تعمل بالكامل داخل المتصفح، بواجهة عربية RTL.

## المزايا الحالية
- المبيعات اليومية: كاش + مصرف 1 + مصرف 2 عند التفعيل.
- فواتير الشراء بالقيمة الإجمالية فقط.
- الموردون والمتبقي عليهم.
- المصاريف.
- الموظفون والمرتبات الثابتة.
- الصندوق والمصارف.
- التحويل بين الحسابات.
- سجل الحركات.
- تقرير شهري مبسط.
- إعداد أرصدة افتتاحية.
- حفظ محلي LocalStorage.

## تشغيل محلي
افتح ملف `index.html` مباشرة في المتصفح.

## GitHub Pages
ارفع الملفات الأربعة إلى مستودع GitHub، ثم فعّل Pages من إعدادات المستودع واختر النشر من فرع `main` والمجلد الجذر `/`.

## ملاحظة مهمة
هذه النسخة تحفظ البيانات على الجهاز نفسه فقط. المرحلة التالية هي ربطها بقاعدة بيانات سحابية لكي تظهر نفس البيانات على الهاتف والكمبيوتر.
